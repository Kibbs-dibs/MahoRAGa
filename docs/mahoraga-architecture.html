MahoRAGa — Project Aletheia Architecture

Autonomous multi-agent RAG for AI literature · LangGraph pipeline · three-layer global memory · self-correcting generation

Query Pipeline (online)

  • • Router — classify intent + reformulate
  • • Retriever — Neo4j PPR + FAISS + BM25, RRF-fused
  • • Evaluator — 100-pt rubric, weak → search
  • • Search APIs — Crossref/OpenAlex/S2 fallback
  • • Pruner — AttentionRAG micro-window compression
  • • Generator — synthesis + Critic re-audit loop

Three-Layer Memory

  • • Neo4j — ontology, fact triples, provenance, PPR
  • • FAISS — 384-d dense vectors, cosine (IndexFlatIP)
  • • BM25 — lexical index + cross-encoder rerank
  • • Fused at retrieval via Reciprocal Rank Fusion
  • • SQLite — chat sessions, messages, query audits

Ingestion & Backends

  • • PyMuPDF parse → structure-aware chunking
  • • Regex fact extraction → Neo4j graph
  • • arXiv watcher — autonomous harvest + dedup
  • • LLM: Ollama → OpenAI → Anthropic/NIM → offline
  • • Gradio UI + FastAPI /api/v1/* surface
